Put your letterhead image(s) here.

1. Header / letterhead image:
   File name: letterhead.png
   Recommended size: approx. 1600px wide x 350px tall (or similar wide banner),
   PNG or JPG. This image is shown at the top of every printed report page.

2. Footer image (optional):
   File name: letterhead-footer.png
   Only needed if your existing letterhead design has a separate footer band
   (address, accreditation logos, etc). If this file is not present, the app
   automatically shows a simple text footer instead.

If neither file is present, the app automatically falls back to a clean
text-based header/footer so the app always works out of the box.

No code changes are needed after adding these files — just refresh the page.
